====================================

Ваш проект: https://github.com/mitrofanovrv-svg/KartuliGO
Ваше приложение: https://mitrofanovrv-svg.github.io/KartuliGO/

ПЕРЕД ОБНОВЛЕНИЕМ
В старой версии приложения откройте Профиль и сохраните резервную
копию прогресса (JSON). Не удаляйте приложение с iPhone!

ШАГ 1. Распакуйте архив KartuliGO_v0.3.zip на Windows.
ШАГ 2. Откройте репозиторий GitHub по ссылке выше.
ШАГ 3. Нажмите Add file -> Upload files (Добавить файл -> Загрузить файлы).
ШАГ 4. Перенесите ВНУТРЕННИЕ ФАЙЛЫ и папку icons из распакованного архива.
       Не загружайте сам ZIP. Важно: index.html в корне репозитория.
ШАГ 5. Подтвердите Commit changes.
ШАГ 6. Через несколько минут откройте адрес приложения.
ШАГ 7. На iPhone полностью закройте КартулиГО и откройте его снова.
       Если не обновилось, откройте адрес сайта в Safari, обновите и подождите.
ШАГ 8. Профиль должен показывать версию 0.3.0.

В КартулиГО 0.3 работают 11 уроков, 33 буквы, 12 заданий на урок,
новая дорожка уроков, сердечки, XP и возврат ошибок.

Прогресс из 0.2 специально сохраняется под тем же ключом хранилища.
Тем не менее рекомендуется сделать резервную копию перед обновлением.

БЕСПЛАТНО: никакие подписки и платный аккаунт Apple не требуются.
GitHub Pages на публичном репозитории работает на бесплатном тарифе.

Озвучивание грузинского зависит от наличия грузинского голоса в iPhone.
Живые аудиозаписи и распознавание речи пока отсутствуют.
