# КартулиГО 🇬🇪 — бесплатный грузинский с русского

**Версия 0.3.0** · Устанавливаемое веб-приложение (PWA) для iPhone и других устройств. Без подписки, без регистрации, без платных API.

## Что уже работает

- Вертикальная дорожка из 11 уроков с последовательной разблокировкой.
- 33 буквы грузинского алфавита.
- 12 заданий в каждом уроке: выбор перевода, подбор пар, сборка предложений из слов (для словарных уроков).
- Пять сердечек, не ограничивающих доступ к обучению; ошибки возвращаются в конце урока.
- Очки XP, ежедневная серия, экран награды.
- Локальное повторение слов, резервное копирование и восстановление прогресса.
- Офлайн-работа после успешной первой загрузки и кэширования PWA.
- Прогресс из v0.1/v0.2 сохраняется под прежним ключом `gamardzhoba_progress_v1`.

## Обновление существующей версии (GitHub Pages)

1. **Рекомендуется:** на установленной v0.2 открой «Профиль» → «Создать резервную копию» и сохрани JSON-файл.
2. Скачай архив v0.3 и распакуй его на компьютере.
3. Открой уже существующий репозиторий `mitrofanovrv-svg/KartuliGO`.
4. Нажми `Add file` → `Upload files`, загрузи **содержимое** распакованной папки, включая `icons` (а не сам ZIP-файл).
5. Подтверди `Commit changes`. Существующие файлы проекта с теми же именами должны быть заменены.
6. Подожди, пока GitHub Pages завершит публикацию. Адрес не меняется:
   `https://mitrofanovrv-svg.github.io/KartuliGO/`
7. Перезагрузи веб-страницу и полностью закрой/открой установленное приложение, если старая версия ещё находится в кэше. В «Профиле» должна отображаться **v0.3.0**.

Если приложение выглядит старым, попробуй снова открыть адрес в Safari и обновить страницу через 1–3 минуты: Service Worker должен получить новую версию. **Не удаляй установленную PWA и не очищай данные Safari до создания резервной копии**, иначе локальный прогресс может пропасть.

## Первое добавление на iPhone

Открой адрес в **Safari** → значок «Поделиться» → «На экран Домой» → «Добавить». После первой полной загрузки открой приложение с домашнего экрана ещё раз, затем проверь работу в авиарежиме.

## Важно

- Озвучивание грузинских слов использует только грузинский голос устройства. Если такого голоса нет, кнопка честно сообщит об этом; записи носителей пока **не добавлены**.
- Проверка произношения через микрофон в версии 0.3 отсутствует.
- Результаты находятся в локальном хранилище конкретной установки/браузера. Данные не синхронизируются между устройствами. Для переноса нужен экспорт/импорт JSON.
- Оригинальный интерфейс и учебные примеры написаны для КартулиГО. Никакие изображения, уроки и исходники Duolingo не включены.
- Для GitHub Pages репозиторий на бесплатном тарифе должен оставаться общедоступным.

## Технологии

Простой HTML + CSS + JavaScript, Manifest, Service Worker. Без внешних зависимостей, внешних API, аналитики и базы данных на сервере.
