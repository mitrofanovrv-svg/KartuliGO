# КартулиГО v0.5.0

Бесплатное офлайн-PWA для изучения грузинского языка с русского на iPhone. Самостоятельная реализация игровых механик, вдохновлённых языковыми приложениями. Не использует исходники, изображения, логотипы и учебные материалы Duolingo.

## Что нового в 0.5.0

- **Разделы обучения:** нажми на зелёную шапку модуля, чтобы увидеть темы и уроки со своими описаниями.
- **Ежедневные задания:** отдельная вкладка «Награды» с тремя задачами, которые сбрасываются по календарному дню на устройстве.
- **Награды за задания:** виртуальные кристаллы, которые можно получить только один раз за выполненную дневную задачу.
- **Сундуки на дорожке:** 4 сундука, открывающиеся после определённых уроков; награда выдаётся однократно.
- **Более богатая дорожка:** чередование игровых уровней, тематических разделов и наград.
- **Совместимость прогресса:** сохранён исходный ключ `gamardzhoba_progress_v1` для перехода с 0.1–0.4.

Ранее существовавшие функции сохранены: изучение грузинских слов вместе с русской транскрипцией, картинки, соединение пар, перевод слов и предложений, аудирование, тренировка речи через запись микрофона (без автоматической оценки), XP, серия дней, ошибки и повторение, офлайн-режим, переключение тем.

## ВАЖНО о голосе

Аудио остаётся из v0.4 (экспериментальный роботизированный eSpeak). Это не исправление грузинской озвучки и НЕ эталон произношения. Мы не использовали APK Duolingo или его аудиофайлы. Грузинский нейросетевой голос нужно подготовить и проверить отдельно с носителем; не полагайся на текущий синтез для тренировки произношения.

## Как обновить на GitHub Pages

1. В работающей версии приложения перейди в «Профиль» и сохрани резервную копию прогресса.
2. Распакуй ZIP **в отдельную папку**. Загружай содержимое папки, а не ZIP целиком.
3. Открой https://github.com/mitrofanovrv-svg/KartuliGO и выбери **Add file → Upload files**.
4. Выдели все файлы и папки из архива (`index.html`, `app.js`, `styles.css`, `audio-map.js`, `sw.js`, `manifest.webmanifest`, `audio/`, `icons/`, README) и перенеси их в корень репозитория, заменяя соответствующие старые файлы. Затем нажми **Commit changes**.
5. Подожди окончания публикации GitHub Pages и открой https://mitrofanovrv-svg.github.io/KartuliGO/ в Safari. Обнови страницу, а если запускается старая версия с домашнего экрана, закрой и открой приложение ещё раз.
6. Открой «Профиль» и убедись, что отображается `v0.5.0`. Проверь XP, уроки и новый экран «Награды».

Не удаляй иконку PWA и не очищай данные Safari без резервной копии: это может уничтожить локальный прогресс.

## Что проверено

Проверено `node --check` для JavaScript, наличие всех статических ресурсов service worker, тест без браузера (имитация DOM) с проходом первого урока, начислением XP, двумя проверками защиты от повторной выдачи наград и сохранением прежнего ключа прогресса.

**Что не проверено:** визуальное отображение на iPhone, поведение Safari/PWA после публикации, естественность грузинского голоса, поддержка записи с микрофона на конкретном телефоне. Для этого потребуется ручной тест на iPhone.

## Техническое устройство

- HTML, CSS, JavaScript без платных сервисов или серверной базы данных.
- Локальный прогресс — `localStorage`.
- Офлайн — Cache Storage и Service Worker.
- Все задания и изображения разработаны для КартулиГО. Внешние учебные данные и медиа Duolingo не включены.
