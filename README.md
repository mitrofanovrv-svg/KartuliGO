# КартулиГО 🇬🇪 — версия 0.4.0

Бесплатное устанавливаемое веб-приложение для изучения грузинского с русского на iPhone. Оригинальный интерфейс и векторные иллюстрации; механика вдохновлена короткими игровыми уроками Duolingo, но не содержит чужих исходных кодов, персонажей и графики.

## Что нового

- **Полностью новая дорожка из 11 разговорных уроков:** приветствие, вежливость, еда, числа, знакомство и город. С первого урока изучаем реальные слова и фразы; буквы появляются между заданиями. Алфавит из 33 букв доступен отдельно.
- **Русская транскрипция** грузинских слов и нескольких составных фраз; её можно отключить в профиле.
- **Новые игровые упражнения:** знакомство со словом; перевод в обе стороны; выбор предмета по картинке; подбор слов и картинок; подбор переводов; поиск букв; составление фраз и подсказки по нажатию на грузинское слово; задания на слух.
- **82 пробные звуковые записи** слов, отдельных букв и коротких фраз — роботизированный грузинский, синтезированный бесплатным движком eSpeak. Работают без интернета после загрузки PWA. Доступна медленная скорость. **Это экспериментальный синтез, не запись носителя языка.** Он может быть неточен, особенно в сложных согласных, поэтому ещё не пригоден как безусловный эталон произношения.
- **Тренировка речи через микрофон**, если браузер позволяет записывать звук: записать себя, остановить, прослушать; можно пропустить. **Автоматической оценки произношения нет.** Запись не отправляется на сервер, удаляется после выхода из задания.
- **Награды и прогресс:** пять сердечек без блокировок, XP, кристаллы, ежедневная серия, Kartuli Score, отметки достижений, учёт новых слов, время и точность прохождения, повторение ошибок.
- **Тёмная/светлая тема**, оригинальный талисман-гранат (статичный прототип), локальное резервное копирование, работа офлайн без подписок.

## Сохранение прогресса с v0.3

Используется тот же ключ локального хранилища `gamardzhoba_progress_v1`.

- **Старые XP, ежедневная серия, история повторений и уроки сохраняются.**
- Однако старый урок `Алфавит · часть 1` **не засчитывается в новую разговорную дорожку**: это другой материал. Старые уроки остаются в истории и не удаляются; новая дорожка начинается с «Первых слов».
- Перед обновлением всё равно сделайте резервную копию через **Профиль → Скачать резервную копию**.

## Установка обновления на действующем GitHub Pages

1. Распакуйте ZIP на компьютере.
2. Откройте публичный репозиторий `https://github.com/mitrofanovrv-svg/KartuliGO`.
3. **Add file → Upload files**. Перетащите *содержимое распакованной папки* в корень репозитория, сохраняя папки `audio/` и `icons/`. **Не загружайте ZIP целиком.**
4. В списке должны быть `index.html`, `app.js`, `audio-map.js`, `styles.css`, `manifest.webmanifest`, `sw.js`, `README.md` и папки `audio` и `icons`.
5. Нажмите **Commit changes**. Проверьте **Settings → Pages**, источник `main / (root)`.
6. Откройте `https://mitrofanovrv-svg.github.io/KartuliGO/` в Safari, дождитесь публикации и обновления кэша, затем полностью закройте и повторно откройте приложение с домашнего экрана iPhone.
7. В **Профиле** должна отображаться **версия 0.4.0**. Если видна старая — подождите и ещё раз откройте страницу в Safari. **Не удаляйте PWA и не очищайте данные Safari до создания резервной копии.**

## Проверка на iPhone

- Откройте «Первые слова»: сначала слова «привет», «спасибо», «да», «нет» с русской транскрипцией и буквенными заданиями.
- Пройдите урок до конца; проверьте экран с XP, кристаллами, Kartuli Score и открытие следующего урока.
- В уроке «Напитки и хлеб» проверьте картинки, подбор пар и кнопку динамика.
- В профиле проверьте переключение темы и транскрипции.
- В разделе «Практика» ознакомьтесь с ограничениями синтезированной речи.
- После завершения начальной загрузки попробуйте открыть установленную PWA в авиарежиме и проверить аудио.

## Технически

HTML + CSS + JavaScript, Service Worker, локальное хранилище, оригинальные SVG-рисунки, локальные MP3. Нет платных сервисов, аналитики, регистраций, платных API или удалённой базы данных. Сайт может бесплатно публиковаться из публичного репозитория GitHub Pages. Настоящее тестирование Safari на физическом iPhone остаётся за пользователем.

Звуковые файлы `audio/*.mp3` созданы при помощи бесплатной программы **eSpeak 1.48.15**, голос `ka` (грузинский). Проект eSpeak: https://espeak.sourceforge.net/ . Звуки экспериментальные: для качественного курса заменим их проверенными записями носителей.
