КАРТУЛИГО v0.2 — бесплатное PWA для изучения грузинского
========================================================
Дата: 18.10.2026

ВОЗМОЖНОСТИ
- 33 грузинские буквы (мхедрули), 11 уроков, 63 учебные карточки.
- Карточки для запоминания; тесты с четырьмя ответами.
- XP, серия дней, пройденные уроки, адаптивное повторение (1/3/7/14/30 дней).
- Локальное хранение прогресса; экспорт и импорт JSON-копии.
- Офлайн-работа после первого посещения и кэширования файлов.
- Без рекламы, учётной записи, трекеров, платных API и внешних библиотек.

КАК ЗАПУСТИТЬ НА WINDOWS (ПРОВЕРКА)
1. Распакуй содержимое ZIP в папку, например C:\KartuliGO.
2. Установи бесплатный Python (если его нет), открой Windows Terminal в папке.
3. Выполни: python -m http.server 8000
4. Открой на ноутбуке: http://localhost:8000
Для сохранения в iPhone нужен URL с HTTPS; адрес localhost работает только на этом ПК.

КАК БЕСПЛАТНО РАЗМЕСТИТЬ ДЛЯ IPHONE (GITHUB PAGES)
1. Создай бесплатный аккаунт на https://github.com (если ещё нет).
2. Создай новый PUBLIC репозиторий с именем, KartuliGO.
3. На странице репозитория выбери Add file > Upload files, загрузи содержимое
   распакованной папки: index.html, app.js, styles.css, manifest.webmanifest,
   sw.js и папку icons с тремя файлами PNG. ВАЖНО: файлы должны лежать в
   корне репозитория (а icons — внутри icons), не внутри KartuliGO_v0.2.
   README.txt загружать необязательно.
4. Нажми Commit changes.
5. Открой Settings > Pages > Build and deployment > Source: Deploy from a branch.
   Выбери Branch: main, Folder: /(root), нажми Save.
6. Дождись появления ссылки вида https://USERNAME.github.io/KartuliGO/
   (это не наш готовый URL, а пример: USERNAME — твой логин).
7. Открой эту ссылку в Safari на iPhone. Через «Поделиться» выбери
   «На экран Домой»; если есть переключатель «Открывать как веб-приложение»,
   оставь его включённым. Нажми «Добавить».
8. Открой и пройди один урок при наличии интернета. Затем проверь, что
   приложение открывается в авиарежиме. Первое кэширование требует сети.

ВНИМАНИЕ
- Для GitHub Pages с бесплатным тарифом репозиторий должен быть публичным.
  Код виден всем; личный прогресс туда НЕ загружается, он остаётся на iPhone.
- После удаления приложения/очистки данных Safari прогресс может исчезнуть.
  В разделе «Профиль» есть резервное копирование/восстановление.
- iOS может удалять данные при нехватке места. Не игнорируй резервные копии.
- Кнопка озвучивания сработает ТОЛЬКО если iOS располагает грузинским голосом.
  Подтверждённой записи носителя и проверки произношения в версии 0.1 нет.
- Русская транскрипция приблизительная и не передаёт все грузинские звуки.
- Поддержка 100% офлайн относится к урокам и тестам после кэширования.
- Для изменения содержимого загрузи новые версии файлов и обнови CACHE в sw.js,
  чтобы iPhone подхватил новую офлайн-версию.
- Это самостоятельный учебный проект, не связанный с Duolingo.
